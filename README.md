# 🍽️ PDA Εστιατορίου — Python

Ένα εκπαιδευτικό project σε **Python** για τη διαχείριση ενός εστιατορίου μέσω κονσόλας. Η εφαρμογή επιτρέπει τη δημιουργία και διαχείριση παραγγελιών, την παρακολούθηση των τραπεζιών, τον υπολογισμό λογαριασμών και την επιλογή τρόπου πληρωμής.

---

## ✨ Δυνατότητες

- 🪑 Διαχείριση **9 τραπεζιών**, οργανωμένων σε διάταξη 3 × 3.
- 🆕 Δημιουργία νέας παραγγελίας σε διαθέσιμο τραπέζι.
- 🍽️ Προβολή των προϊόντων μιας ενεργής παραγγελίας.
- ➕ Προσθήκη επιπλέον προϊόντων σε υπάρχουσα παραγγελία.
- ➖ Αφαίρεση προϊόντων από μια παραγγελία.
- 🧾 Αυτόματος υπολογισμός και εμφάνιση του λογαριασμού.
- 💳 Επιλογή τρόπου πληρωμής: κάρτα ή μετρητά.
- ℹ️ Προβολή πληροφοριών τραπεζιού, όπως κατάσταση, προϊόντα, συνολικό ποσό και τρόπος πληρωμής.
- 📊 Επισκόπηση της κατάστασης όλων των τραπεζιών.
- 🧹 Κλείσιμο τραπεζιού και επαναφορά των στοιχείων της παραγγελίας.
- 🔢 Έλεγχος αριθμητικών επιλογών μέσα στα καθορισμένα όρια.
- ↩️ Επιστροφή στο κύριο μενού από τις αντίστοιχες λειτουργίες.

## 🗂️ Δομή αρχείων

```text
PDA-University-Project/
├── main.py          # Εκκίνηση εφαρμογής και κύριο μενού
├── functions.py     # Λειτουργίες παραγγελιών και διαχείρισης τραπεζιών
├── pda_general.py   # Μενού, κατάλογος, τιμές και αρχικά δεδομένα
└── README.md        # Περιγραφή του project
```

### Ρόλος κάθε αρχείου

- **`../../main.py`** — εμφανίζει το κύριο μενού και καλεί τη λειτουργία που αντιστοιχεί στην επιλογή του χρήστη.
- **`../../functions.py`** — περιλαμβάνει τις λειτουργίες για παραγγελίες, προϊόντα, λογαριασμούς, πληρωμές και τραπέζια.
- **`../../pda_general.py`** — περιέχει το μενού της εφαρμογής, τον κατάλογο προϊόντων, τις τιμές και τις αρχικές δομές δεδομένων.

## ▶️ Εκτέλεση

### Απαιτήσεις

- **Python 3**
- Δεν απαιτούνται εξωτερικές βιβλιοθήκες για τη βασική εκτέλεση.

### Βήματα

1. Κατέβασε ή κάνε clone το repository.
2. Άνοιξε τον φάκελο του project σε ένα IDE, όπως το PyCharm, ή σε ένα terminal.
3. Βεβαιώσου ότι τα `../../main.py`, `functions.py` και `pda_general.py` βρίσκονται στον ίδιο φάκελο.
4. Εκτέλεσε:

```bash
python main.py
```

Σε ορισμένα συστήματα μπορεί να χρειαστεί:

```bash
python3 main.py
```
